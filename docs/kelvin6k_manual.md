# Kelvin6K Operating Manual

## Nozzle Clog Procedure
If material flow drops or the layer becomes too narrow, the nozzle may be clogged.
Stop the pump, release system pressure, then soak the nozzle in solvent for ten
minutes and clear it with the cleaning rod. Never clear a clog while the pump is
pressurised.

## Layer Width Calibration
Layer width is measured in pixels by the vision system and converted using
PIXELS_PER_MM. Place a reference block of known width at the print distance,
count the pixels it spans, and divide by its width in millimetres.

## Daily Maintenance
Clean the printing pipe every four hours of operation. Inspect the accelerator
coupling daily and check pump seals weekly.
